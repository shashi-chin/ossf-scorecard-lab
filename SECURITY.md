# Security Policy

## Supported versions

This is a lab repository for exploring [OpenSSF Scorecard](https://github.com/ossf/scorecard).
Treat it as a learning sandbox, not production software.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes (lab) |

## Reporting a vulnerability

If you discover a security issue in this lab setup:

1. Do **not** open a public issue with exploit details.
2. Email the repository owner via their GitHub profile contact, or open a private
   security advisory under **Security → Advisories → New draft security advisory**.
3. Include: affected path/workflow, impact, and steps to reproduce.

You should receive an acknowledgment within a few business days.
